Comment jouer

Monte un circuit, teste-le.

  • Choisis un composant puis place-le sur la zone.
  • Mode Fil : clique sur deux bornes pour les relier.
  • Mode Sonde : clique sur une borne pour mesurer.
  • La gomme retire un composant ou un fil.

Astuce : clique sur un composant placé pour le faire pivoter ou ouvrir ses réglages.
